# Исправления в тестах

## Выполненные исправления

### 1. Добавлен тест для rootReducer

Создан файл `src/slices/__tests__/root-reducer.test.ts` с тестами, которые проверяют:
- rootReducer не мутирует состояние при неизвестном экшене
- rootReducer корректно обрабатывает известные экшены

### 2. Улучшены Cypress тесты

В файле `cypress/e2e/tests.cy.tsx` внесены следующие изменения:

#### Добавлена очистка localStorage и cookies
```typescript
afterEach(() => {
  // Очищаем localStorage и cookies после каждого теста
  cy.clearLocalStorage();
  cy.clearCookies();
});
```

#### Улучшены проверки конструктора
- Теперь проверяется, что ингредиенты действительно добавлены в конструктор, а не просто отображаются на странице
- Используется селектор `[data-testid="constructor"]` для точного определения области конструктора

#### Добавлен тест на номер заказа
- Новый тест `'Проверка корректного номера заказа в модальном окне'`
- Проверяет, что в модальном окне отображается правильный номер заказа (40763)
- Проверяет название заказа "Краторный био-марсианский бургер"

#### Улучшены проверки модального окна ингредиентов
- Теперь проверяется наличие и содержимое модального окна напрямую
- Проверяются значения БЖУ для конкретного ингредиента (белки: 80, жиры: 24, углеводы: 53, калории: 420)
- Убрана зависимость от URL для проверки модального окна

#### Улучшена проверка очистки конструктора
- Теперь проверяется, что после очистки конструктор полностью пуст
- Проверяется отсутствие всех добавленных ингредиентов (булки и начинки)

### 3. Добавлены data-testid атрибуты

Добавлены атрибуты для тестирования в следующие компоненты:

#### Конструктор бургера
```typescript
<section className={styles.burger_constructor} data-testid="constructor">
```

#### Модальное окно ингредиента
```typescript
<div className={styles.modal} data-testid="ingredient-modal">
```

#### Детали ингредиента
```typescript
<div className={styles.content} data-testid="ingredient-details">
```

#### Модальное окно заказа
```typescript
<div data-testid="order-modal">
```

#### Номер заказа
```typescript
<h2 className={styles.title} data-testid="order-number">
```

## Селекторы для тестов

В тестах используются следующие селекторы:
- `[data-testid="constructor"]` - область конструктора
- `[data-testid="ingredient-modal"]` - модальное окно ингредиента
- `[data-testid="order-modal"]` - модальное окно заказа
- `[data-testid="ingredient-details"]` - детали ингредиента
- `[data-testid="order-number"]` - номер заказа
